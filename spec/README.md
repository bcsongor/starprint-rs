# Star command specifications

The manuals this library implements, kept here for reference. Both are
the latest revisions Star Micronics publishes (checked 2026-08-21).

| File | Title | Revision | Source |
|---|---|---|---|
| `star-line-mode-command-specifications-rev1.80.pdf` | Line Thermal Printer — STAR Line Mode Command Specifications | Rev 1.80 (2020-08-26), 288 pages | <https://www.starmicronics.com/support/Mannualfolder/starline_cm_en.pdf> |
| `dot-impact-star-command-specifications-rev1.91.pdf` | Dot Impact Printer — STAR Command Specifications | Rev. 1.91 (2014-03-17), 111 pages | <https://www.starmicronics.com/support/Mannualfolder/dot_star_cm_en.pdf> |

The thermal manual covers `Builder<StarLine>`; the dot impact manual
covers `Builder<Impact>` (SP700 series, in "STAR Mode" as opposed to its
ESC/POS emulation). Copyright Star Micronics Co., Ltd.
