# Contributing

Printer reports are useful, especially for models we haven't tested.
[Open a printer report](https://github.com/bcsongor/starprint-rs/issues/new?template=printer-report.md)
with the model, app version, settings and a photo of the output.

For other bugs, include the steps to reproduce and what you expected.
For a feature request, describe what you want to print or automate.

## Change the code

Follow the [README setup](README.md#build-the-app-from-source) to run the app.
[AGENTS.md](AGENTS.md) covers the architecture, hardware constraints and required checks.

Keep changes focused and update the relevant docs. Add tests for behaviour changes.
For printer output changes, say which hardware you tested and include a photo.
If you couldn't test on a printer, say so.

Open an issue before a large change so we can agree on the approach.
